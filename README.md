# Splunk Security Monitoring Lab

Author: Nicholas Voronetskis

## Status

Documentation in progress. This README is an initial project outline based on my portfolio. Source files, screenshots, and reproducible results have not yet been added to this repository. The checklist below tracks documentation and verification work; it is not a claim that every step is complete.

## Goal

Collect Windows security events and practice searches, alerting, and incident triage in a controlled lab.

## Tools

- Splunk
- Windows 11
- Kali Linux
- VirtualBox

## Setup and walkthrough checklist

- [ ] Document the virtual machines and isolated network.
- [ ] Configure Windows event collection and confirm events arrive in Splunk.
- [ ] Generate controlled test events and develop SPL searches.
- [ ] Configure an alert and record the investigation and validation steps.

Exact installation commands, versions, and configuration details will be recorded after the implementation is checked. No runnable setup is included in this initial documentation commit.
